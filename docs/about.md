# 关于我

我是 Jaron Lu，有 10 年以上证券金融行业客户端工程经验，目前专注 AI Agent 与 LLM 应用工程。

我的关注点不是把聊天界面接到模型上，而是把长期处理过的状态、权限、安全、错误恢复和发布约束，迁移到可验证的 Agent 系统中。
